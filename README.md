# 私生滚开：夜路突围 · Mobile

这是从 `C:\Users\贺兰\Desktop\onersisheng` 赛车原型改出的手机端竖屏版本，采用与现有俯视素材一致的平行车道视角。

## 玩法

- 三车道自动前进，点击左右按钮、左右滑动或使用 `← → / A D` 换道。
- 躲开新闻车、地勤车、护栏、花盆、行李车等障碍。
- 道具无需手动使用，拾取路上的油柑、小兔手雷或麦麦后会立即生效；油柑获得 8 秒无敌并加速 20%，最后 2 秒会闪烁提示，小兔手雷清除当前车道目标，麦麦降低追车压力。
- 跑完 8300m 抵达安全点，前 1000m 为无障碍、无道具的安全路段；之后速度和障碍密度会随进度提升，系统会为车身长度和换道距离预留安全车道。正常行驶的自然压力较低，撞击会显著增加压力；车辆耐久归零或追车压力达到 100% 时失败。

## 本地运行

在项目根目录启动任意静态服务器，例如：

```powershell
cd C:\Users\贺兰\Desktop\onersishengmobile
npx --yes serve .
```

也可以使用 VS Code Live Server 等静态服务器打开 `index.html`。

## 文件结构

- `index.html`：竖屏画布、HUD、触控按钮和首页/结算层。
- `src/main.js`：游戏状态、三车道逻辑、生成器、碰撞、技能和绘制。
- `src/styles.css`：手机端布局、HUD 和霓虹夜景视觉。
- `assets/images/`：从参考项目复用的车辆、障碍和技能素材。
